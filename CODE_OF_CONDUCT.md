# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) como código de conduta.

Em resumo: seja respeitoso, aceite críticas construtivas com maturidade, foque no que é melhor para a comunidade e não tolere assédio ou discriminação de qualquer tipo.

## Aplicação

Relate comportamentos inaceitáveis pelo relato privado do GitHub (aba **Security → Report a vulnerability**) ou diretamente a um mantenedor. Todos os relatos são analisados com sigilo e imparcialidade, e os mantenedores podem remover contribuições, advertir ou banir participantes.
